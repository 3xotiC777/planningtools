# Historial de cambios

## 1.2.0

- Instalación de dependencias separada para cada usuario en `%LOCALAPPDATA%`.
- Caché local del código para evitar fallos de archivos bajo demanda de OneDrive.
- Conservación de la última copia local válida cuando OneDrive no responde.
- Validación corregida de permisos de escritura en la carpeta compartida.
- Instalación con paquetes binarios y límites de espera para redes corporativas.
- Preparación del proyecto para control de versiones y distribución mediante GitHub.
